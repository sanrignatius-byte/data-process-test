## Query

> Under the pipeline’s preprocessing stage, how would the architecture reduce deployment overhead because the dropdown-selected Eliquis module produce synthetic label content yet still require manual effort under prototype constraints?

## Answer

The overhead is front-loaded into preprocessing rather than repeated at deployment: the pipeline inserts data interrogation and label generation before model development, and the ecosystem serves that label through a generator, repository, data host, and viewer. This is consistent with the selectable Eliquis-by-state component being the Probabilistic Model module, which produces synthetic probabilistic label content while still requiring some manual effort.
