### 2.2 GPU OOM
- **问题**：A5000（24GB）+ `batch_size=32` → Qwen3-Embedding-4B（7.6GB）OOM
- **解决**：SLURM 脚本改为 `--gres=gpu:a6000:1`（48GB），`--batch-size 8`

### 2.3 Qwen3-Embedding-8B 模型不完整
- **问题**：`models/Qwen3-Embedding-8B/` 只有第3个 shard（共4个），无法加载
- **解决**：从脚本中删除 8B 评测，仅保留 4B

### 2.4 Graph expansion 命名空间不匹配（关键 bug）
- **问题**：
  - Corpus passage ID 格式：`{doc_id}_{doc_id}_{type}_{N}`（N 从 0 开始）
  - Chunk 图节点 ID 格式：`{doc_id}_chunk_{i}`、`{doc_id}_para_{i}`
  - `multimodal_elements.json` 中 element ID 格式：`{doc_id}_{type}_{K}`（K 从 1 开始）
  - 三个命名空间完全不重叠 → 初版 `eval_graph_expanded_retrieval.py` 构建的邻接表有 0 个节点，graph expansion 输出 +0.0000
- **解决**：
  1. 用 `position_idx` 作为桥接字段：`element.position_idx` → chunk 的 `paragraph_indices` 映射到 chunk_id
  2. 处理 0/1-indexed 差异：corpus 用 0-indexed（`formula_0`），elements 用 1-indexed（`formula_1`），需要 N → K-1 转换
  3. 处理类型别名：corpus 用 `fig`，elements 用 `figure`
  - 修复后覆盖率：662/1798 → **1082/1798**（60%），邻接表 645 → **1018 节点**

## 三、实验结果

### 3.1 基线对比（Qwen3-Embedding-4B，top-100）

| 实验 | 语料说明 | R@100 | MRR | NDCG@10 |
|------|---------|-------|-----|---------|
| baseline（原始文本） | 1798 passages，formula/fig 原始文本 | 9.51% | 0.0080 | 0.0089 |
| **v1（enriched）** | 同上，context_before/after + caption 拼接 | **20.51%** | **0.1047** | **0.1177** |
| v2（+chunks） | v1 + 1708 chunk 虚拟节点 | 16.86% | 0.0822 | 0.0801 |
| v3（+summaries） | v2 + 2767 LLM summary 虚拟节点 | 14.65% | 0.0606 | 0.0547 |

> **结论**：加入 chunk/summary 节点会稀释语料导致排名下降（corpus dilution）。v1 enrichment 单独效果最好，召回率相对原始基线提升 +115%。

### 3.2 Graph Expansion 实验（在 v1 结果上展开）

**sweep**: decay ∈ {0.3, 0.5, 0.7, 0.9}，max_hops ∈ {1, 2}

最优配置：decay=0.5，max_hops=1

| 指标 | Dense 基线 | +Graph Expansion | Δ |
|------|-----------|-----------------|---|
| R@100 | 20.51% | 20.72% | **+0.21%** |
| MRR | 0.1047 | 0.1036 | -0.0011 |
| NDCG@10 | 0.1177 | 0.1147 | -0.0030 |
| R@5 | 14.59% | 13.74% | -0.85% |

> **结论**：Graph expansion 对 R@100 有微弱正增益（+0.21%），但 MRR 和 NDCG@10 均略有下降。

## 四、根本原因分析

### 4.1 为什么 R@100 只有 20.51%（理论上限远不止于此）

M4query_v1 数据集的正例分布：
- 共 1892 条 qrels，平均每个 query 有 4 个正例
- **899/1798 passages 是公式（raw LaTeX）**，例：`$$D(Mx, My) \leq d(x,y)$$`
- **842/1798 passages 是图片**，文本仅为 `[Image: xxx.jpg]`（平均 41 字符）
- 只有 30/1798 passages 有 `enriched_content`（MODORA 生成的图片描述）
- **219/473 queries 在 top-100 内完全没有命中**

### 4.2 为什么 Graph Expansion 效果有限

- 每条 query 的 3-5 个正例通常来自**不同 section**（跨模态、跨位置）
- 同一 chunk/section 内的邻居 passages 往往和 query 无关
- 40% 的 corpus passages 无法映射到 chunk 图（因为不在 `multimodal_elements.json` 中）

### 4.3 MRR 的结构性瓶颈

- 当 query 有命中时，中位首命中排名 = 8（MRR ≈ 0.125）
- 大量正例是图片/公式，embedding 相似度天然偏低
- 要提升 MRR，根本出路是：为图片生成 VLM caption，为公式生成自然语言描述
