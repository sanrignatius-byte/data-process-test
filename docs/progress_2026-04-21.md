## 二、新脚本

### `scripts/build_chunk_corpus.py`

**功能**：chunk 检索语料构建 + qrels 重映射。

```
输入：
  paragraph_chunks_n400.json     ← chunk 图结构（paragraph_indices）
  multimodal_elements_enriched.json  ← element caption + enriched_content
  qrels.jsonl                    ← 原始 element_id 级别的 qrels

输出（per out-dir）：
  corpus.jsonl   passage_id=chunk_id，text = 段落文本 + [Element]: caption enriched_content
  qrels.jsonl    element_id → parent_chunk_id 重映射
  build_report.json
```

**n400 验证结果**：
- corpus: 1963 passages（只取 57 gold docs）
- 473 queries 全覆盖，4 个 element 未找到对应 chunk（1.6% 损失）
- 25.9% 的 chunk 有 element 注入

**n500 验证结果**：
- corpus: 1703 passages，473 queries 全覆盖

### `scripts/eval_chunk_graph_rerank.py`

**功能**：专为 chunk_id 格式 passage 设计的图 rerank。原有 `eval_graph_topk_rerank.py` 把 passage 当 element_id 解析，chunk_id 格式会完全失败。

**图信号两层**：
1. `chunk_sequence`：相邻 chunk 互相 boost（阅读顺序邻近）
2. `explicit_projected`：hub_candidates 里的 element pair (a,b) → 通过 elem→chunk 映射 → (chunk_a, chunk_b)，跨段落语义桥接

**6 个对照 config**：
```
seq_only / static_prior
seq_only / static+neighbor
exp_only / static_prior
exp_only / static+neighbor
seq+exp  / static_prior
seq+exp  / static+neighbor
```

## 四、核心设计变化（对应 4.19.md §5.3）

### 旧设计（失败根因）
```
corpus = element passages（2809）+ chunk passages（1864）= 4673
qrels  = element_id（不含 chunk_id）
问题：chunk 加进去就是稀释，qrels 不认账，评估失效
```

### 新设计（本次实现）
```
corpus = chunk passages only（1963，57 docs）
  每个 chunk text = 段落文本
                  + [Element]: caption + enriched_content（注入）
qrels  = element_id → parent_chunk_id（重映射）
```
