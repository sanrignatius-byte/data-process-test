# 专利申报凝练稿：基于异构文档图约束的多模态多证据检索训练数据自动构造方法

## 一句话主张

本项目发明了一种**以文档真实引用关系为约束的多模态多证据训练数据自动构造方法**。

它不是简单的 PDF 解析，也不是让大模型自由出题，而是先把论文中的图、表、公式、段落、章节等内容组织成一张“可信证据图”，再从图上寻找真实存在的多跳证据链，最后让大模型在证据链约束下生成可训练的检索样本。

答辩时可概括为：

> 我们把复杂文档变成一张可信证据图，并用这张图约束大模型自动生产多模态、多证据、可训练的检索数据。

## 发明背景

现有多模态检索训练数据通常是“一个问题对应一张图”或“一个问题对应一段文本”，难以覆盖真实科研文档和企业技术文档中的复杂证据关系。

在真实文档中，一个问题的答案往往需要多个证据共同推导。例如：公式定义方法，表格给出实验结果，图展示趋势，正文解释适用条件。人工标注这类多证据数据成本高、规模受限；直接让大模型生成问题又容易出现关系编造、答案幻觉，或生成单个证据就能回答的“伪多跳”样本。

本项目的出发点是：文档作者在正文中已经通过 “Figure 3”“Table 2”“Eq. 7”“\ref{}” 等方式显式标注了证据之间的关系。这些关系本身就是天然的、高可信的多证据线索。

## 拟解决的问题

本项目拟解决的问题是：

> 如何从大量复杂文档中，自动、低成本、可信地构造“必须联合多个证据才能回答”的多模态检索训练数据。

具体包括：

- 如何从 PDF/LaTeX 文档中恢复图、表、公式、段落之间的真实关系。
- 如何自动发现适合生成多证据问题的证据组合，而不是随机拼接元素。
- 如何约束大模型生成 grounded 的 query、answer 和 reasoning chain。
- 如何判断生成样本确实需要多个证据共同回答。
- 如何打包成可用于检索模型训练的 triplet 数据。

## 核心技术方案

整体流程如下：

```text
PDF / LaTeX 文档
  → 多模态元素抽取
  → 显式引用关系建图
  → hub 与多跳证据路径挖掘
  → 图路径约束的大模型生成
  → 多跳必要性质量控制
  → 检索训练 triplet 打包
```

核心步骤包括：

1. 从 PDF/LaTeX 中抽取 figure、table、formula、paragraph、section、chunk 等多粒度元素。
2. 利用文档作者写下的显式引用关系，如 “Figure N”“Table M”“Eq. K”“\ref{}”，构建多模态异构证据图。
3. 在证据图中识别连接多个模态的 hub 节点和 2-hop/3-hop 多跳路径。
4. 将证据路径、桥接段落、章节摘要、元素描述作为约束输入，让大模型生成 query、answer 和 reasoning chain。
5. 通过规则检查和 LLM judge 验证：单个证据不能独立回答，答案必须由多个证据共同支撑。
6. 将通过质量控制的样本打包为检索训练 triplet，包括多正例、同文档 hard negative、跨文档 random negative。

## 核心创新点

### 1. 把作者引用关系转化为数据生成约束

项目不是让大模型凭空理解整篇论文并自由出题，而是把论文中真实存在的引用关系转化为机器可用的证据图。

这样可以显著降低大模型编造关系的风险，使生成的问题建立在文档原本存在的逻辑连接上。

### 2. 从文档图中自动挖掘多模态多证据链

项目通过 hub 节点、桥接关系和多跳路径，自动发现图、表、公式、段落之间的证据组合。

这些候选不是随机采样，而是来自文档结构中的真实连接，因此天然适合生成“必须联合多个证据才能回答”的问题。

### 3. 用图路径约束大模型生成训练样本

大模型的作用不是自由创作，而是在证据路径、桥接文本和元素描述约束下生成 query、answer 和 reasoning chain。

这使得生成样本既具有自然语言表达能力，又保持证据可追溯性。

### 4. 面向“多证据必要性”的质量控制

项目的质量控制不仅检查文本是否通顺，还专门验证：

- 单个证据是否不能独立回答问题。
- 答案是否必须由多个证据共同推出。
- query 是否泄漏视觉 anchor 或关键数值。
- answer 是否存在无法由证据支撑的幻觉内容。

这是普通文本生成 QC 或普通数据清洗不具备的能力。

## 建议保护点

主保护点建议聚焦为：

> 一种基于异构文档图约束的多模态多证据检索训练数据自动构造方法。

从属保护点可覆盖：

- PDF 多模态元素与 LaTeX/PDF 显式引用关系融合建图。
- figure、table、formula、paragraph、section、chunk 的统一异构图建模。
- 基于 hub scoring 的多跳跨模态证据路径选择。
- 图路径约束的大模型 query/answer/reasoning chain 生成。
- 单元素消融与答案 grounding 的多跳必要性验证。
- 元素级证据到 chunk 级检索单元的映射。
- 同文档 hard negative、跨文档 random negative 和视觉/文本负样本重平衡。

## 有益效果

本项目已经形成可验证的数据产出和技术效果：

- 已交付两版主数据集，共 **16,308 条 triplet**。
- 对应 corpus 共 **318,362 条 passage**，覆盖图、表、公式、段落、chunk、section 等多粒度证据。
- 图结构用于检索 rerank 后，R@10 从 **0.6195 提升到 0.6913**。
- 在平衡测试中，figure 检索提升约 **+10.3pp**，table 检索提升约 **+8.3pp**。
- PDF-first 路线已验证可行，MinerU 中的显式引用恢复可覆盖大部分 LaTeX 引用关系，降低对 LaTeX 源码的依赖。

因此，该方案的价值不只是生成一个数据集，而是形成了一套可复用的数据生产工艺：能够把大量复杂文档自动转化为高质量、多模态、多证据、可训练的检索数据。

## 项目价值

该方法可用于：

- 多模态检索模型训练。
- 科研论文问答与文献检索。
- 企业技术文档 RAG。
- 产品手册、标准文档、专利文档的复杂证据问答。
- 需要多图、多表、多公式联合理解的专业知识库构建。

面向专利评审时，最重要的表达是：

> 本项目的创新不在于“解析 PDF”或“调用大模型生成问题”，而在于把文档内部真实存在的证据关系建成图，并用这张图约束大模型生成可训练的多证据检索数据。
